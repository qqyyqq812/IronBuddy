# 04 语音控制与飞书周报

本章说明语音控制和飞书周报的演示路径。语音和飞书都依赖外部服务，现场
展示时必须准备手动降级路径。

## 语音控制入口

语音服务由板端进程提供，主页面通过接口读取语音状态、手动录音状态和对话
结果。真实语音不可用时，可以用页面按钮或文本输入完成同一业务闭环。

- 语音状态：`/api/voice_debug`
- 手动录音开始：`/api/voice_manual/start`
- 手动录音停止：`/api/voice_manual/stop`
- 语音轮次：`/api/voice_turn`

## 推荐命令

现场命令应短、清楚、容易被 STT 识别。以下命令只作为展示模板。

| 场景 | 示例命令 | 预期结果 |
| --- | --- | --- |
| 唤醒教练 | `教练` | 进入听取指令状态 |
| 切换动作 | `切换到深蹲` | 主页面运动模式变更 |
| 查询建议 | `今天适合怎么练` | 生成或朗读训练建议 |
| 推送周报 | `发送训练周报` | 触发飞书推送 |
| 停止播报 | `停止` | 结束当前播报或录音 |

## 飞书周报

飞书周报用于把训练计划、训练总结或演示报告发到指定会话。手册只写配置项
名称，不记录真实值。

- `FEISHU_APP_ID`
- `FEISHU_APP_SECRET`
- `FEISHU_CHAT_ID`
- `FEISHU_WEBHOOK`

## 降级路径

如果麦克风、音箱、STT 或飞书外网不可用，仍然要保留可展示结果。

1. 使用手动录音按钮替代唤醒词。
2. 使用主页面文本输入替代真实 STT。
3. 使用 `dry_run` 或页面预览展示飞书卡片结构。
4. 先展示训练总结，再说明飞书发送依赖外部账号配置。
